# Wiederholung PHP Prob

**1. Cheat Sheet der wichtigsten PHP Befehle und Konstrukte.**

*Php Syntax*
```php
<?php
//PHP code
?>
```

*Variablen und Ausgabe*
```php
$txt = "W3Schools.com";
echo "I love $txt!";
echo "This ", "string ", "was ", "made ", "with multiple parameters.";
```

*Strings*
```php
$x = "Hello";
$y = "World";
$z = $x . " " . $y;   //Mit Punkten Strings dranhängen
echo $z;
```

*Konstanten*

`define(CONSTANT_NAME, value);`

*Klassen*
```php
class Car {
  public $color;
  public $model;
  public function __construct($color, $model) {
    $this->color = $color;
    $this->model = $model;
  }
  public function message() {
    return "My car is a " . $this->color . " " . $this->model . "!";
  }
}

$myCar = new Car("red", "Volvo");
var_dump($myCar);
```

```php

/*

*/
```

*Bedingungen*
```php
if (5 > 3)  // Vergleich zwischen zwei Werten
```

*Arrays*

*Funktionen*
```php
//mit Parameter

    return $a + $b;
}

```

*Switch Cases*
```php

  case label1:
    //code block
    break;
  case label2:
    //code block;
    break;
  case label3:
    //code block
    break;

```

*Wichtige Befehle*
- echo – gibt Inhalte aus.
- var_dump() - gibt den Datentyp und den Wert aus
- isset() – prüft, ob eine Variable gesetzt und nicht null ist.
- empty() – prüft, ob ein Wert als leer gilt.
- count() – zählt die Elemente eines Arrays.

*Superglobals*

Superglobals sind vordefinierte Variablen in PHP, die in allen Gültigkeitsbereichen verfügbar sind.
- `$_GET:` Liest Daten aus URL-Parametern.
- `$_POST:` Liest per POST übertragene Formulardaten.
- `$_SERVER:` Enthält Informationen über den Server und die aktuelle Anfrage.
- `$_SESSION:` Speichert benutzerbezogene Daten über mehrere Seitenaufrufe hinweg.
- `$_COOKIE:` Liest Cookie-Daten aus.
- `$_FILES:` Enthält Informationen zu hochgeladenen Dateien.
- `$_ENV:` Enthält Umgebungsvariablen.
- `$GLOBALS:` Ermöglicht den Zugriff auf globale Variablen.
- `$_REQUEST:` Kann GET-, POST- und Cookie-Daten enthalten, abhängig von der PHP-Konfiguration.
