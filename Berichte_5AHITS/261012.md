*Wichtige Befehle*
- echo – gibt Inhalte aus.
- var_dump() - gibt den Datentyp und den Wert aus
- isset() – prüft, ob eine Variable gesetzt und nicht null ist.
- empty() – prüft, ob ein Wert als leer gilt.
- count() – zählt die Elemente eines Arrays.

*Superglobals*

Superglobals sind vordefinierte Variablen in PHP, die in allen Gültigkeitsbereichen verfügbar sind.
- `$_GET:` Liest Daten aus URL-Parametern.
- `$_POST:` Liest per POST übertragene Formulardaten.
- `$_SERVER:` Enthält Informationen über den Server und die aktuelle Anfrage.
- `$_SESSION:` Speichert benutzerbezogene Daten über mehrere Seitenaufrufe hinweg.
- `$_COOKIE:` Liest Cookie-Daten aus.
- `$_FILES:` Enthält Informationen zu hochgeladenen Dateien.
- `$_ENV:` Enthält Umgebungsvariablen.
- `$GLOBALS:` Ermöglicht den Zugriff auf globale Variablen.
- `$_REQUEST:` Kann GET-, POST- und Cookie-Daten enthalten, abhängig von der PHP-Konfiguration.

*auswertung.php*

```php
<?php
$anzahl = filter_var(
    $_POST["anzahl"] ?? null,
    FILTER_VALIDATE_INT
);

$eingaben = $_POST["noten"] ?? []; // leeres Array fals keine Noten übertragen

if (
    $anzahl === false ||
    !is_array($eingaben) ||
    count($eingaben) !== $anzahl
) {
    exit("Ungültige Eingaben.");
}

$noten = [];

foreach ($eingaben as $eingabe) {
    $note = filter_var(
        $eingabe,
        FILTER_VALIDATE_INT,
        ["options" => ["min_range" => 1, "max_range" => 5]]
    );

    if ($note === false) {
        exit("Alle Noten müssen zwischen 1 und 5 liegen.");
    }

    $noten[] = $note;
}

$durchschnitt = array_sum($noten) / count($noten);
$beste = min($noten);
$schlechteste = max($noten);

$positiv = 0;
$negativ = 0;

foreach ($noten as $note) {
    if ($note <= 4) {
        $positiv++;
    } else {
        $negativ++;
    }
}
?>

<h1>Notenübersicht</h1>

<table border="1" cellpadding="8">
    <tr>
        <th>Matrikelnummer</th>
        <th>Note</th>
    </tr>

    <?php foreach ($noten as $index => $note): ?> <!-- durchläuft das Array $noten und liest dabei Index und Wert jeder Note aus -->
        <tr>
            <td><?= $index + 1 ?></td>
            <td><?= $note ?></td>
        </tr>
    <?php endforeach; ?>
   
</table>

<h2>Statistik</h2>

<p>
    Durchschnitt:
    <?php echo number_format($durchschnitt, 2, ","); ?>
</p>

<p>Beste Note: <?php echo $beste; ?></p>
<p>Schlechteste Note: <?php echo $schlechteste; ?></p>
<p>Positive Noten: <?php echo $positiv; ?></p>
<p>Negative Noten: <?php echo $negativ; ?></p>

<br>

<a href="index.php">Neue Auswertung starten</a>

</body>
</html>
```

### Erklärung
 
Auf der Seite `index.php` wurde eine Eingabe zur Anzahl der Noten erstellt, damit auf der nächsten Seite die richtige Anzahl der Eingabefelder angezeigt werden kann. Dazu wurde ein Formular genutzt mit einem Zahlen-Eingabe-Feld und einem Submit-Button.   

Wenn der Submit-Button gedrückt wird, wird die Seite `noten.php` aufgerufen (siehe `action="noten.php"`).    
 
Auf der Seite `noten.php` wurde eine Eingabe für die Noten aller Schüler (nach Matrikelnummer) erstellt.   

Die Anzahl der Noten ist im Superglobal-Array `$_POST` gespeichert, da wir das Formular der vorherigen Seite per POST übermittelt haben. Es wird gefiltert, ob die Anzahl ein gültiger Ganzwert ist.   

Das Hidden-Feld am Anfang des Formulars wird benötigt, damit die Anzahl der Noten an die nächste Seite mit übergeben wird.   

Danach folgen Eingabefelder für alle Noten mittels eine Schleife. Beim Klick auf dem Submit-Button wird die Seite `auswertung.php` aufgerufen.   
 
In `auswertung.php` wird am Anfang die Fehlerbehandlung durchgeführt und das Noten-Array aus der Super-global-Variable geholt. Dabei wird überprüft, ob die Anzahl ein gültiger Ganzwert ist, die Noten zwischen 1 und 5 liegen und alle Noten eingegeben wurden. Danach werden alle Noten im Array `$noten` gespeichert.   

Als nächstes werden die Werte für die Statistik ermittelt, also Durchschnitt, beste Note, schlechteste Note, etc.   

Die Notenübersicht wurde in Tabellenform dargestellt, wobei `$note` und `$index` als Laufvariablen in der foreach-Schleife dienen. Für jeden Schleifendurchlauf wird also eine neue Tabellenzeile mit Matrikelnummer des Schülers und seiner Note erstellt.   

Nach der Tabelle wird die Statistik ausgegeben. Der Durchschnitt wurde mittels `number_format()` auf 2 Nachkommastellen begrenzt und als Trennzeichen wurde "," gewählt.   

Zum Schluss erfolgt eine Verlinkung auf die erste Seite, also `index.php`, für eine neue Eingabe.

**Passwort-Generator**

- Länge über ein Formular festlegen
- Zufälliges Passwort erzeugen
- Optionen: Groß-/Kleinbuchstaben, Zahlen, Sonderzeichen

*index.php*

```php
<?php

function isPasswordValid(string $password): bool
{
    return preg_match('/[0-9]/', $password) === 1
        && preg_match('/[a-z]/', $password) === 1
        && preg_match('/[A-Z]/', $password) === 1
        && preg_match('/[^a-zA-Z0-9]/', $password) === 1;
}

function generateUserPassword($length)
{
    $characters = '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ!@#$%^&*()_+-=';
    $password = '';
    $max = strlen($characters) - 1;

    //so lange das Passwort nicht den Anforderungen entspricht, wird ein neues Passwort generiert
    do {
        $password = '';

        for ($i = 0; $i < $length; $i++) {
            $password .= $characters[random_int(0, $max)]; //Zufallszeichen aus characters nehmen und dranhängen -> random_int(min, max)
        }

    } while (isPasswordValid($password) == false);

    return $password;
}



if (ISSET($_GET["length"]) && $_GET["length"] >= 8 && $_GET["length"] <= 32)
{
    $length = $_GET["length"];
    $password = generateUserPassword($length);
    echo("<br>Dein Passwort lautet: <b>$password</b>");
}

else
{   
    echo("<br><br>Gib die gewünschte Länge von deinem Passwort ein! <br>Die Länge muss zwischen 8 und 32 Zeichen liegen.");

    ?>
    <form action="index.php" method="GET">
        <input type="text" name="length" placeholder="Gib die gewünschte Länge von deinem Passwort ein!" >
        <input type="submit" value="submit">
    </form>
<?php
}
?>
```

### Erklärung

Das ganze Programm ist in `index.php`. Wenn man die Seite aufruft findet man ein Formular, wo man die Länge seines gewünschten Passwortes eingeben soll. Ich habe mich für den GET Parameter entschieden, da die *Länge* vom Passwort nicht unbedingt zu verstecken ist.

Ob das Formular abgegeben wurde oder nicht, wird mit dem `if (ISSET($_GET["length"]) && $_GET["length"] >= 8 && $_GET["length"] <= 32)` abgefragt. Zusätzlich muss das Passwort min. 8 bis max. 32 Zeichen haben- denn je länger das Passwort, desto sicherer ist es. Wenn diese Anforderungen nicht erfüllt sind, kommt man nicht weiter und das Formular bleibt so stehen.

Wenn die eingegebene Länge >= 8 und <= 32 ist, wird der Wert vom Get-Parameter in die Variable `length` gespeichert: `$length = $_GET["length"];` 

Um das Passwort zu erstellen, habe ich 2 Funktionen geschrieben; 1. `generateUserPassword` und 2. `isPasswordValid`. 


*generateUserPassword*

Hier wird das Passwort erstellt; Ich habe in die Variable (string) `characters` alle Ziffern, Kleinbuchstaben, Großbuchstaben und Sonderzeichen geschrieben. Danach wird die Länge des Strings ermittelt.

Jetzt zum Erstellen: 

do-while Schleife : Das Passwort wird so lange zurückgesetzt und neu per Zufall in einer eigenen Schleife erstellt (`$password .= $characters[random_int(0, $max)];`), bis das neu erstellte Passwort auf Richtigkeit geprüft wurde -> `isPasswordValid`. Wenn dies so ist, wird das fertige Passwort mit `return $password;` zurückgeliefert. 

*isPasswordValid*

Das Passwort wird per string übergeben und der Rückgabewert ist `True` oder `False`.

Es wird ein `True` zurückgegeben wenn min. eine Ziffer, ein Großbuchstabe, ein Kleinbuchstabe und ein Sonderzeichen enthalten ist. Es müssen alle 4 vorkommen -> sonst ist es `False`
