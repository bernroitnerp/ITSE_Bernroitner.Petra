# Wiederholung PHP Prob

## 1. Cheat Sheet der wichtigsten PHP Befehle und Konstrukte

*Php Syntax*
```php
<?php
//PHP code
?>
```

*Variablen und Ausgabe*
```php
$txt = "W3Schools.com";
echo "I love $txt!";
echo "This ", "string ", "was ", "made ", "with multiple parameters.";
```

*Strings*
```php
$x = "Hello";
$y = "World";
$z = $x . " " . $y;   //Mit Punkten Strings dranhängen
echo $z;
```

*Konstanten*

`define(CONSTANT_NAME, value);`

*Klassen*
```php
class Car {
  public $color;
  public $model;
  public function __construct($color, $model) {
    $this->color = $color;
    $this->model = $model;
  }
  public function message() {
    return "My car is a " . $this->color . " " . $this->model . "!";
  }
}

$myCar = new Car("red", "Volvo");
var_dump($myCar);
```

*Kommentare*
```php
// Einzeiler

/* 
mehrere 
Zeilen
*/
```

*Bedingungen*
```php
if (5 > 3)  // Vergleich zwischen zwei Werten
{ 
  echo "Have a good day!";
}
```

*Schleifen*
```php
for ($i = 0; $i < 5; $i++) {
    echo $i;
}

foreach ($namen as $name) {
    echo $name;
}
```
*Arrays*
```php
$cars = array("Volvo", "BMW", "Toyota");
echo $cars[0]; //direkt ausgeben (1. Element ausgeben), sonst in einer Schleife
```

*Funktionen*
```php
//mit Parameter
function addieren($a, $b) {
    return $a + $b;
}

//ohne Parameter
function myMessage() {
  echo "Hello world!";
}

//Aufrufen
myMessage();
```

*Switch Cases*
```php
switch (expression) {
  case label1:
    //code block
    break;
  case label2:
    //code block;
    break;
  case label3:
    //code block
    break;
  default:
    //code block
}
```

*Wichtige Befehle*
- echo – gibt Inhalte aus.
- var_dump() - gibt den Datentyp und den Wert aus
- isset() – prüft, ob eine Variable gesetzt und nicht null ist.
- empty() – prüft, ob ein Wert als leer gilt.
- count() – zählt die Elemente eines Arrays.

*Superglobals*

Superglobals sind vordefinierte Variablen in PHP, die in allen Gültigkeitsbereichen verfügbar sind.
- `$_GET:` Liest Daten aus URL-Parametern.
- `$_POST:` Liest per POST übertragene Formulardaten.
- `$_SERVER:` Enthält Informationen über den Server und die aktuelle Anfrage.
- `$_SESSION:` Speichert benutzerbezogene Daten über mehrere Seitenaufrufe hinweg.
- `$_COOKIE:` Liest Cookie-Daten aus.
- `$_FILES:` Enthält Informationen zu hochgeladenen Dateien.
- `$_ENV:` Enthält Umgebungsvariablen.
- `$GLOBALS:` Ermöglicht den Zugriff auf globale Variablen.
- `$_REQUEST:` Kann GET-, POST- und Cookie-Daten enthalten, abhängig von der PHP-Konfiguration.

**Notenverwaltung**

- Mehrere Noten über ein Formular eingeben
- Noten in einem Array speichern
- Durchschnitt, beste/schlechteste Note und Anzahl der positiven Noten berechnen
- Ausgabe als HTML-Tabelle

*Index.php*
```php
<!-- Hier wird die Anzahl der Noten eingegeben -->
<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <title>Notenrechner</title>
</head>
<body>

<h1>Notenrechner</h1>

<form action="noten.php" method="post"> <!-- Nach submit wird "noten.php" aufgerufen-->
    <label>Anzahl Noten:</label>
    <input type="number" id="anzahl" name="anzahl" required>
    <br><br>

    <button type="submit">Nächster Schritt</button>
</form>

</body>
</html>
```

*Noten.php*

```php
<?php
$anzahl = filter_var(   // Anzahl der Noten auslesen
    $_POST["anzahl"] ?? null,
    FILTER_VALIDATE_INT,
);
?>

<h1>Noten eingeben</h1>

<form action="auswertung.php" method="post">

    <input type="hidden" name="anzahl"
           value="<?= $anzahl ?>"> <!-- Beim Submit wird die Anzahl der Noten an die Nächste Seite übergeben -->

    <?php for ($i = 1; $i <= $anzahl; $i++): ?>

        <label for="note<?= $i ?>"> Schüler <?= $i ?>: </label>
        <input type="number" id="note<?= $i ?>" name="noten[]" min="1" max="5" required>
        <br><br>

    <?php endfor; ?>

    <button type="submit">Auswertung anzeigen</button>

</form>

</body>
</html>
```

*auswertung.php*

```php
<?php
$anzahl = filter_var(
    $_POST["anzahl"] ?? null,
    FILTER_VALIDATE_INT
);

$eingaben = $_POST["noten"] ?? []; // leeres Array fals keine Noten übertragen

if (
    $anzahl === false ||
    !is_array($eingaben) ||
    count($eingaben) !== $anzahl
) {
    exit("Ungültige Eingaben.");
}

$noten = [];

foreach ($eingaben as $eingabe) {
    $note = filter_var(
        $eingabe,
        FILTER_VALIDATE_INT,
        ["options" => ["min_range" => 1, "max_range" => 5]]
    );

    if ($note === false) {
        exit("Alle Noten müssen zwischen 1 und 5 liegen.");
    }

    $noten[] = $note;
}

$durchschnitt = array_sum($noten) / count($noten);
$beste = min($noten);
$schlechteste = max($noten);

$positiv = 0;
$negativ = 0;

foreach ($noten as $note) {
    if ($note <= 4) {
        $positiv++;
    } else {
        $negativ++;
    }
}
?>

<h1>Notenübersicht</h1>

<table border="1" cellpadding="8">
    <tr>
        <th>Matrikelnummer</th>
        <th>Note</th>
    </tr>

    <?php foreach ($noten as $index => $note): ?> <!-- durchläuft das Array $noten und liest dabei Index und Wert jeder Note aus -->
        <tr>
            <td><?= $index + 1 ?></td>
            <td><?= $note ?></td>
        </tr>
    <?php endforeach; ?>
   
</table>

<h2>Statistik</h2>

<p>
    Durchschnitt:
    <?php echo number_format($durchschnitt, 2, ","); ?>
</p>

<p>Beste Note: <?php echo $beste; ?></p>
<p>Schlechteste Note: <?php echo $schlechteste; ?></p>
<p>Positive Noten: <?php echo $positiv; ?></p>
<p>Negative Noten: <?php echo $negativ; ?></p>

<br>

<a href="index.php">Neue Auswertung starten</a>

</body>
</html>
```
